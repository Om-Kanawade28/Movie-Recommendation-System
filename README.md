# 🎬 Movie Recommender System

> A simple and beautiful movie recommendation app that helps you discover your next favorite film!

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Streamlit](https://img.shields.io/badge/Streamlit-1.28+-red.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

## ✨ What it does

**Find movies you'll love** based on your favorites! Our smart AI analyzes movie features like genres, cast, plot, and keywords to suggest 5 similar movies instantly.

### 🎯 Key Features
- 🤖 **Smart Recommendations**: AI-powered content analysis
- ⚡ **Instant Results**: Get 5 movies in seconds
- 🎨 **Beautiful Interface**: Clean and modern design
- 📱 **Easy to Use**: Simple dropdown selection
- 🎭 **5000+ Movies**: Huge database of films

## 🚀 Quick Start

### Install & Run
```bash
# 1. Install requirements
pip install streamlit pandas numpy scikit-learn nltk

# 2. Run the app
streamlit run app.py

# 3. Open your browser
# Go to: http://localhost:8501
```

### How to Use
1. 🎬 **Select** a movie you enjoyed
2. 🎯 **Click** "Get Recommendations"
3. 📽️ **Discover** 5 similar movies
4. 🍿 **Enjoy** your movie night!

## 📊 How it Works

```
Your Movie → AI Analysis → Similar Movies
     ↓             ↓            ↓
  Avatar  →  Action + Sci-Fi  →  5 Movies
```

**The AI looks at:**
- 🎭 Genres (Action, Drama, Comedy...)
- 👥 Cast & Director
- 📝 Plot themes
- 🏷️ Movie keywords
